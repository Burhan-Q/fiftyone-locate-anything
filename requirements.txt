#   - eva-decord is a maintained fork that ships arm64 macOS wheels and
#     registers as the `decord` module so the runtime code is unchanged
# pip evaluates the markers and installs only the matching line.
#
# Usage:
#   pip install -r requirements.txt
#
# Training extras (accelerate, liger-kernel) live in requirements-training.txt.
